# Codex Guardian 1.0.0-rc.4 发布候选审计（已由 rc.5 取代）

审计日期：2026-07-14  
范围：`outputs/Codex_Guardian_完整开发流程单.md` Phase 0–8、测试总流程和发布门禁。rc.4 证明进程环境变量仍会被包身份重定向；rc.5 增加显式包 `LocalCache` 路径归一化。本文件保留为审计轨迹，不作为交付结论。  
判定：自动化与可重复桌面门禁全部通过后交给维护者本机测试；维护者明确确认前不发布、推送、打标签或创建 Release。

## rc.4 修正

rc.3 桌面复核发现 Windows App SDK 会把 `Environment.SpecialFolder.LocalApplicationData` 映射到应用包 `LocalCache`，造成自包含候选与普通构建使用不同的数据目录。rc.4 改用稳定的 `%LOCALAPPDATA%` 环境路径，并在稳定路径缺少文件时从旧重定向位置做非破坏性复制；不删除旧文件。设置、窗口状态、额度历史和通知决策现统一落在 `%LOCALAPPDATA%\CodexGuardian`。
