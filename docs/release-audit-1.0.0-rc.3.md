# Codex Guardian 1.0.0-rc.3 发布候选审计（已由 rc.4 取代）

审计日期：2026-07-14  
审计范围：`outputs/Codex_Guardian_完整开发流程单.md` Phase 0–8、测试总流程与发布门禁。该候选在桌面复核时发现 Windows App SDK 本地数据路径重定向，已在 rc.4 修正；本文件保留为审计轨迹，不作为交付结论。  
结论规则：自动化与可重复桌面检查通过后，候选包可以交给维护者做本机门禁；维护者明确确认前不得发布、推送、打标签或创建 Release。

## 证据等级

- **自动通过**：由构建、测试或审计脚本直接证明。
- **桌面通过**：已在候选可执行文件中实际操作并观察。
- **设计取舍**：原流程中的可选项被明确排除且记录理由。
- **本机待验**：必须由维护者在其真实显示器、系统会话或长时间使用中确认，不冒充自动通过。

## Phase 0：需求冻结与数据源验证

状态：**自动通过；额度数值一致性由本机清单复核**。

- 默认 Provider 只读 `%USERPROFILE%\.codex\sessions` 中最新的 `payload.rate_limits`，支持当前 Windows 用户下能生成该事件的 Codex 账户与计划。
- `QuotaSnapshot`、新鲜度、Provider 错误和监控契约均独立于 UI；无字段、空窗口、陈旧或损坏事件均 fail closed，不猜测额度。
- Provider 不读取 `auth.json`，不复制 Cookie、密码或令牌，不发起网络请求；断网不会改变本地只读边界。
- 未提供未经验证的“降级额度源”。Provider 不可用时显示 `NO DATA/STALE/EXPIRED`，这是有意的安全降级。
- 证据：`docs/data-source-validation.md`、`docs/provider-contract.md`、Provider/Monitor 测试、诊断 CLI 与网络 API 扫描。

## Phase 1：Quiet Monitor MVP

状态：**自动通过 + 桌面通过；重启/睡眠由本机清单复核**。

- WPF 胶囊显示 5 小时/每周剩余、重置时间与数据新鲜度，支持手动/定时刷新、置顶、托盘、单实例、位置与折叠状态恢复。
- 进程上下文检测覆盖全屏、OBS、PowerPoint、常见 IDE 和用户勿扰；默认主动通知关闭。
- 诊断输出为安全 JSON；运行与设置使用当前用户权限，不要求管理员。
- 证据：零警告 Release 构建、真实本机诊断、候选启动/单实例检查、视觉 QA 和驻留测试。

## Phase 2：历史记录与消耗趋势

状态：**自动通过**。

- JSONL 历史只保存规范化额度字段，支持去重、保留、压缩、损坏行恢复、安全导出与明确清空。
- 30 分钟、2 小时、5 小时、7 天趋势跳过数据缺口、重复时间和重置跳变。
- 存储失败不会阻断实时监控。
- 证据：HistoryStore、ProviderTail、QuotaTrend 测试与隐私扫描。

## Phase 3：预测引擎

状态：**自动通过**。

- 冷启动样本不足时不画未来曲线；预测给出置信度与耗尽最早/最晚范围。
- 时间线用置信带表达不确定性；低置信度范围更宽，重置优先于耗尽结论。
- 回测按 15 个百分点中位绝对误差目标报告；数据缺口、重复时间、重置与 Provider 恢复均有回归测试。
- 证据：预测器、TimelineProjection 与回测测试。

## Phase 4：Advisor 与智能通知

状态：**自动通过 + 桌面通道检查；真实系统操作按钮由本机清单复核**。

- 四级决策、一分钟规则、行动价值、去重、冷却、恶化升级、上下文抑制与静默至重置均在 Core 中实现。
- Windows App SDK 提供原生通知及“打开 Guardian / 静默至重置”操作；不可用时回退本地 WPF 通知。
- 通知决策日志只记录等级、原因、结果和重置时间，不记录工作内容。
- 证据：NotificationCoordinator、ActivationParser、DecisionStore 测试，设置页测试通知与桌面 QA。

## Phase 5：Quota Timeline

状态：**自动通过 + 桌面通过**。

- 支持暂停、轻量、当前、高强度场景，显示历史、重置、保留线、耗尽范围与不确定性带。
- 支持鼠标探索、缩放和键盘游标；无可信预测时只显示实时点。
- 证据：TimelineProjection 测试及候选完整面板视觉 QA。

## Phase 6：额度策略与个性化

状态：**自动通过 + 桌面通过**。

- 提供冲刺、均衡、保守保留策略、任务预算、前后摘要和本地七日周报。
- “个性化分析”可完全关闭；关闭后实时额度和时间线保持可用，策略、任务预算与周报被禁用。
- 报告与预算不保存任务标题、项目名、提示词或回复。
- 证据：QuotaStrategy、TaskBudget、WeeklyReport 测试及设置/完整面板 QA。

## Phase 7：主题、动效与体验

状态：**桌面通过；125%/200% DPI 与真实多显示器由本机清单复核**。

- 极简深色、玻璃和赛博主题不改变数据语义；额度轨道、低能量状态与消耗速度动效有数据含义。
- 减少动效会停用呼吸效果和被动自动展开，核心功能不受影响。
- 全中文与 Full English 可在设置中立即切换并持久化；静态资源与动态状态均重本地化。
- PerMonitorV2 manifest 已嵌入。天气/季节效果作为可选项被明确排除，避免无关网络与位置隐私成本。
- 证据：本地化目录验证、XAML 引用扫描、双语候选视觉 QA、manifest 检查。

## Phase 8：Skill、安装、诊断与开源材料

状态：**自动通过；公开发布明确暂停**。

- Skill 含环境检测、本地包安装、诊断、修复和无删除卸载引导；任何删除都要求用户另行明确授权。
- 候选 ZIP 为 `win-x64` 自包含包，携带 .NET 与 Windows App SDK；安装脚本保留设置和历史。
- README、LICENSE、贡献规范、行为准则、安全策略、隐私、架构、限制、变更日志与 CI 均已准备。
- 证据：Skill 验证、重复安装保留标记检查、诊断/修复执行、ZIP SHA-256 与开源文件审计。
