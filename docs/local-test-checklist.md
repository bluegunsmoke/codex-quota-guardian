# Codex Guardian 本机验收清单

版本：`1.0.0-rc.14`  
原则：本清单全部通过前，不进行 GitHub 发布、推送或 Release。

## 启动与数据

- [ ] 双击 `CodexGuardian.App.exe` 可正常启动，且只出现一个托盘图标。
- [ ] 不先执行新任务直接启动 Guardian；Codex 已登录并运行时，当前可用额度应在约 2–8 秒内由灰色变为有效。随后点击刷新会主动重读，不必等待新的任务事件。
- [ ] 5 小时与每周剩余额度与 Codex 当前显示一致。
- [ ] 重置时间合理，数据状态显示为 `LIVE`；无有效数据时明确显示 `NO DATA`，不伪造数值。
- [ ] 点击刷新后按钮明确反馈“发现新事件 / 没有新事件 / 扫描失败”，没有闪退或明显卡顿。

## 窗口与交互

- [ ] 展开、收起胶囊正常，文字没有裁切或重叠。
- [ ] 首次启动默认停靠屏幕右下角并锁定移动；解除锁定后可拖到任意位置，再次锁定会固定当前位置而不归位。
- [ ] “无感显示模式”可独立开关，并能分别叠加到极简、玻璃、赛博、余烬、极光、苔境、樱墨、霜蓝、深海和日蚀主题。
- [ ] 在设置中切换任一配色时，下方缩略胶囊和桌面胶囊立即同步预览；点击“取消”恢复原外观，点击“保存更改”后重启仍保留。
- [ ] 落樱、初雪、萤火和星雨可叠加到任一配色；开启“减少动态”或隐藏桌面胶囊后环境效果停止。
- [ ] 无感显示保持 5H/7D 百分比一眼可见，悬停时操作按钮恢复清晰，展开内容无裁切。
- [ ] 主窗口常驻桌面时不在任务栏显示按钮，系统托盘图标始终保留。
- [ ] 托盘右键菜单会根据当前状态显示“显示 Guardian / 隐藏 Guardian”，两种动作均有效且不会退出程序。
- [ ] 置顶开关有效；隐藏主窗口后程序留在托盘，用户主动隐藏期间 Passive 不会擅自重新显示窗口。
- [ ] 检测到本地 Codex 会话文件持续变化时只显示低幅轨道流动，不出现“活动中”文字，停止活动约 4 秒后归静。
- [ ] 新额度快照改变剩余比例时显示窗口名与差值，只有对应轨道短促反馈，约 2 秒后归静。
- [ ] 开启“减少动画”后，活动轨道流动停止；额度变化仍可显示静态差值，但不运行闪动或数字位移动画。
- [ ] “登录 Windows 时启动”与“跟随 Codex 启动”互斥；后者默认关闭且启用时不要求管理员权限。
- [ ] 启用跟随启动后退出 Codex 与 Guardian，再次打开 Codex 可在约 5 秒内启动 Guardian并立即刷新；同一轮 Codex 会话中手动退出 Guardian 不会被强制重开。
- [ ] 关闭跟随启动后 `CodexGuardian.Watcher` 在一个检测周期内退出，用户级 Run 值被移除，重启登录后不再常驻。
- [ ] 设置窗口可保存刷新频率、减少动效、勿扰模式和开机启动选项。
- [ ] 在“全中文 / Full English”间切换后，胶囊、完整面板、设置、托盘和动态状态文字立即统一切换，重启后仍保持选择。
- [ ] 关闭个性化分析后，实时额度与时间线仍可用，策略、任务预算和周报被禁用；重新开启后恢复。
- [ ] 时间线能显示历史、预测和不确定性区间；切换使用情景、缩放以及键盘游标不会报错。
- [ ] 125% 和 200% DPI 下窗口无裁切，跨显示器拖动后布局和点击区域正确。

## 安静与隐私

- [ ] 主动通知默认关闭；开启后在勿扰或全屏状态下不会打扰。
- [ ] Ambient 只改变边框、状态图标、数字颜色和呼吸节奏，不弹窗。
- [ ] Passive 自动展开显示预计低额度时间，约 8 秒后收回，无声音、无系统 Toast。
- [ ] 设置页“发送测试通知”能明确显示原生或回退通道；原生通知的“打开 Guardian / 静默至重置”操作有效。
- [ ] `%CODEX_GUARDIAN_HOME%\data`（未设置时为 `%USERPROFILE%\.codex-guardian\data`）中不包含提示词、回复正文、源码、Cookie 或令牌。
- [ ] 连续运行和重启后 `bundle-cache` 大小不增长；`quota-history.jsonl` 永远不超过 16 MB，`notification-decisions.jsonl` 永远不超过 512 KB。
- [ ] 使用安装脚本时篡改 ZIP 或校验值会在解压前失败，发布包旁同时存在 `.zip.sha256` 文件。
- [ ] 应用不要求管理员权限，不触发登录，也不访问账号认证文件。

## 稳定性

- [ ] 连续运行至少 30 分钟，没有崩溃、窗口冻结或持续异常增长的资源占用。
- [ ] 跟随启动 watcher 连续运行 30 分钟时私有内存低于 20 MB、平均 CPU 低于 0.05%，且不创建日志、缓存或网络连接。
- [ ] Windows 重启或注销后（如启用开机启动）能正常恢复。
- [ ] 睡眠后恢复，额度会重新读取且不会把旧值标记为实时数据。

发现问题时，请记录：操作步骤、预期结果、实际结果、截图，以及 Guardian `data` 目录中不含隐私内容的相关诊断信息。
