## 路径兼容性结论

从已打包 Codex 桌面进程启动子进程时，Windows 可能虚拟化新建的 AppData 文件。rc.3–rc.5 的实机复核证明仅归一化路径字符串无法绕过系统层重定向，因此这些候选均未交付。rc.6 使用包上下文不会虚拟化的用户目录：

- 应用：`%USERPROFILE%\.codex-guardian\app`
- 数据：`%USERPROFILE%\.codex-guardian\data`
- 旧数据：仅从原 LocalAppData 位置复制到新数据目录，不删除旧文件。
